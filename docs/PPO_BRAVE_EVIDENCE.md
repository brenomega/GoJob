# Evidência de extensão Brave no Personal Project Operator

Experimento anterior documentou extensão Chromium Manifest V3 + Native Messaging host Python e núcleo Node/SQLite; acesso temporário activeTab/scripting; mensagens tipadas, reservas de envio e idempotência de efeitos incertos. O canal real transmitiu e recuperou mensagens autorizadas em ensaio.

Também houve incidentes com CDP obsoleto, browser lifecycle, Cloudflare, seletor de DOM `#history` obsoleto e perfis. Isso não equivale a permissão para ler cookies ou automatizar logins.

Codex deve inspecionar os artefatos originais no host, comparar com extensões existentes e provar compatibilidade no Brave antes de escolher.
